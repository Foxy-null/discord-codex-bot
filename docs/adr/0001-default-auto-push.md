# 新規作業スレッドの自動プッシュを既定で有効にする

未コミット変更の扱いは[ADR-0002](./0002-auto-commit-and-push.md)で更新した。

Bot
のホストに接続するより、別のローカル環境で変更を取得して確認する運用が多いため、新規作業スレッドでは自動プッシュを既定で有効にする。外部への送信を避けたい作業では
`/start` の `auto_push:false`
を指定でき、設定がない既存スレッドには従来の動作を維持する。

自動プッシュはコミット済みの変更を送る機能とし、未コミットの変更は通知する。作業途中のファイルを一括で自動コミットする方式は採用しない。初回のブランチ改名後を含め、各依頼の正常終了後に作業ブランチを
`origin`
へ送る。失敗・中断・プランモードでは送信せず、既定ブランチへの送信や強制プッシュも行わない。プッシュ失敗時は作業内容を保持し、Discord
に通知する。
